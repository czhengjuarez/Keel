## Requirements

Node 18 or later. Keel is CSS plus framework-agnostic TypeScript class helpers: no React, no runtime dependencies, no build step required for the CSS.

## Install

```bash
npm install @ops-forward/keel
```

Or with pnpm:

```bash
pnpm add @ops-forward/keel
```

This is the only Keel package on npm.

## Add the styles

Import the stylesheet once at your app entry. It includes the design tokens and every component:

```ts
import '@ops-forward/keel/styles.css';
```

Or link it directly from a CDN, pinning the version:

```html
<link rel="stylesheet" href="https://unpkg.com/@ops-forward/keel@0.2.1/src/styles.css">
```

## Load fonts

The system uses three typefaces. Add this to your HTML `<head>`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@600&family=Inter:wght@400;500;600&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

- **Space Grotesk 600** — headings and display text
- **Inter 400 / 500 / 600** — body, UI labels, paragraphs
- **JetBrains Mono 400 / 500** — code, timestamps, metadata

## Use components

Use the CSS classes directly in any framework:

```html
<button class="of-btn of-btn--primary of-btn--md">Book a call</button>
```

Or build the class strings with the TypeScript helpers:

```ts
import { buttonClass, badgeClass, cardClass } from '@ops-forward/keel';

buttonClass({ variant: 'primary', size: 'md' }); // "of-btn of-btn--primary of-btn--md"
```

Look up any component's classes and options from the terminal, offline:

```bash
npx keel ls
npx keel doc button
npx keel check src/**/*.html   # flags invented of-* classes
```

AI agents can start from [/llms.txt](/llms.txt). Every docs page is also available as Markdown by appending `.md` to its URL.

## Dark mode

The stylesheet sets `color-scheme: light dark`, so tokens follow `prefers-color-scheme` automatically via CSS `light-dark()`. To let users override it, set `data-mode` on the root element:

```js
document.documentElement.setAttribute('data-mode', 'dark');
```

See [Dark mode](/dark-mode) for the full guide, including localStorage persistence.
